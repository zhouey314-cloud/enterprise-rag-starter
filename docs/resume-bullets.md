# 企业 RAG Starter — 中文简历项目要点

仅描述公开仓库内可核查的自建参考实现；按岗位挑选，不叠加成多项成果。事实以 [README](../README.md)、[case study](case-study.md) 和实际测试为准。

## AI Engineer / FDE

- 用 Python、SQLite 和静态 JavaScript 实现可追溯知识查询：公开词法演示、可选本地 embedding 语义/混合检索，以及支持 MD/PDF/DOCX 的本地身份文件库。
- 本地库支持 token 对应的租户/角色、来源哈希、版本/生效/过期/删除/冲突处理及 CLI/loopback HTTP；公开网页 scope 仅作演示过滤，不冒充生产 IAM。
- 修复“正确文档返回错误首句”的 Python/浏览器摘录问题；共享十条反例从 2/10 到 10/10，原拒答和权限门禁保留。本轮 49 项 Python、20 项 Node 检查通过。

## AI Product / Solution

- 将来源、权限和拒答要求拆成可演示与可复现流程，清楚区分公开网页、可选模型和本地身份文件库的能力与部署边界。
- 用检索、摘录、引用和拒答的分项证据说明交付状态：本地候选 60/60 必需词法案例通过，全量 60/62，两个语义改写探针失败；没有把失败预期改成拒答。
- 用户已报告审阅 62 条候选，回执保留来源与哈希；未补造逐条人工决议，数据与 expected 仍为 synthetic_unverified，不当作企业准确率或独立 Golden Set。

## 实习 / 校招

- 完成公开参考项目的三条运行路径、测试、CLI/HTTP 复现说明与案例；代码和合成证据均可核查。
