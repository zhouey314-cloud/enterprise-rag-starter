# Architecture and known failures

`rag.py` keeps chunking, provider interfaces, retrieval modes and answer construction separate. The lexical baseline counts query overlap in body and title after access filtering. Local semantic retrieval uses normalized sentence embeddings and cosine similarity; hybrid merges lexical and semantic ranks via weighted reciprocal-rank fusion. Access filtering precedes both branches. The browser demo implements lexical only.

Lexical mode misses synonyms and can surface an irrelevant sentence from a relevant document. Semantic mode can retrieve related but non-answering text; its 0.30 similarity threshold is provisional for this tiny fictional corpus, not a calibrated production cutoff. A citation proves which chunk was used, not that the answer is semantically correct. The Golden Set is synthetic and unverified by a business expert. Production extension: typed parser results, incremental ingestion, document versioning, authenticated ACLs, reranker with trace, model groundedness rubric and human-reviewed regression cases.
